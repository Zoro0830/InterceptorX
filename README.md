# InterceptorX

A web application security testing platform inspired by Burp Suite for HTTP/HTTPS interception and request analysis.

## Current Features

- HTTP/HTTPS interception using mitmproxy
- Live request logging
- Custom interception scripting

## Planned Features

- Request repeater
- JWT decoder
- Security header scanner
- API testing tools
- Traffic dashboard

## Tech Stack

- Python
- mitmproxy
- Flask
- SQLite

## Current Status

Initial proxy interception engine implemented successfully.
